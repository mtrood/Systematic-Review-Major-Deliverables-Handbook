# Stage 3: Execute Search

---

## 3.1 Execute Database Searches

- **Record keeping** — keep a spreadsheet recording the following for each database searched:
  - Database provider and the specific database searched
  - Number of records identified in the search
  - Number of duplicates automatically deleted by the database search engine
  - Date of search
  - Your syntax
  - Any other relevant information — e.g., idiosyncrasies specific to that database that aren't applicable to others (e.g., that you could not use 'near operators' in the syntax)

## 3.2 Execute Reference List Search

- If extracting references by hand (e.g., from a research repository or from Google Scholar), add a search tag to the notes section in your reference manager
  - E.g., in EndNote — if systematically extracting the references from each included study in a similar review, add a *tag* like the following into the notes field of each record extracted from that review:

## 3.3 Execute Grey Literature Search

- Much of the guidance from sections 3.1 and 3.2 applies here too

> <span style="background-color: #ffe0e0; padding: 2px 5px; border-radius: 3px;">⚠️ **Critical steps:**
> - Keep a detailed log of where you are searching and how
> - Each time you add an individual record from grey literature, ensure it has a tag like the Figure 2 example
> - E.g., if you are first extracting all references to an EndNote library, add a tag to the 'Research notes' field of each reference you extract from the source. This way all you will have to do is search your library for the tag (as an exact phrase) to quickly see all the references you extracted from that source.</span>
